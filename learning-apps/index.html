Learning Apps

소리, 스토리, 발표로 이어지는 PERS 학습앱

퍼스 학습앱은 파닉스 학습, 스토리 스크립트 만들기, TED Kids 발표 연습을 하나의 성장 흐름으로 연결합니다. 아래 앱은 실제 기능을 붙여 넣기 전에도 수업 방향과 학부모 안내를 보여줄 수 있는 시작 화면입니다.

01 Phonics

파닉스를 학습하는 앱

선생님이 제시하는 소리를 듣고, 아이가 빠르게 말하고 그림과 문자로 연결하는 파닉스 학습앱입니다.

  • 소리 카드와 사이트워드 반응
  • 퀵드로잉 미션 연결
  • 파닉스 적용력 체크

02 Script

스토리를 만드는 스크립트 앱

읽은 책이나 그림 장면을 바탕으로 아이가 말할 수 있는 짧은 영어 스크립트를 만드는 앱입니다.

  • 캐릭터, 장소, 문제 선택
  • 짧은 발표 문장 구성
  • 선생님 피드백 메모
스크립트 앱 열기
03 TED Kids

스토리를 발표하는 TED Kids 앱

완성된 스크립트를 아이의 목소리와 발표 태도로 바꾸는 키즈 프레젠테이션 연습 앱입니다.

  • 오프닝, 본문, 마무리 흐름
  • 발표 타이머와 큐카드
  • 자신감과 전달력 체크
